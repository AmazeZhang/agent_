# SPEC 02 — M2：数据集划分、指标、可优化资源与候选过滤

- 版本：v0.1（草稿）
- 日期：2026-08-07

## 1. 数据集划分（防泄漏核心）

### 1.1 三个集合

| 集合 | 用途 | 划分比例（40–80 条总量） | 规则 |
|---|---|---|---|
| 开发集 dev | APO/GEPA 优化时的候选评测（rollout 重跑） | 60% | 可反复使用 |
| 验证集 val | 候选接受/拒绝、回归门控、版本更新决策 | 20% | 可反复使用 |
| **留出集 holdout** | 最终报告唯一数据来源 | 20% | **任何优化调用禁止触碰** |

### 1.2 划分机制

- `data/partition.py`：按任务 id hash 划分，输出 `dev.jsonl / val.jsonl / holdout.jsonl` + `partition_manifest.json`（含划分 hash，防篡改）。
- 脚本断言：`holdout` 的 id 集合在所有优化入口（Trainer dataset、GEPA evaluator、APO val）被拒绝（raise）。
- 诊断用 7 条上游失败轨迹与本集划分**独立**（它们是"诊断方法评测"的样本，不是闭环优化样本），二者不得混用。

### 1.3 与现有 7 条失败基准的关系

- 7 条上游失败轨迹 → 继续用于 AgentRx 诊断能力的评测（现有 comparison.json），**不进入** APO/GEPA 的优化循环。
- 闭环的失败样本来自 M1 基线采集（tau2 自然任务中失败的轨迹）。

## 2. 闭环指标定义

### 2.1 主指标

| 指标 | 定义 | 使用位置 |
|---|---|---|
| 任务成功率 success@1 | 开发/验证集上 tau2 DB 校验通过的比率（一次 rollout） | 候选排序、门控 |
| 成本 cost/instance | 单任务 API token 成本（沿用 LiteLLM 计价） | 候选过滤（成本上限） |
| 副作用 side effect | 非目标文件修改数、测试文件改动数（tau2 环境内可查 git diff） | 门控否决项 |

### 2.2 过程指标（诊断半环）

| 指标 | 定义 | 使用位置 |
|---|---|---|
| 类别正确率 | AgentRx 10 类分类 vs 人工标签 | 诊断质量跟踪 |
| 失败步骤误差 | 诊断步骤 vs 人工标注步骤（±2 容忍） | 诊断质量跟踪 |

过程指标只做监控，**不进入**闭环主目标；闭环只优化主指标。

### 2.3 多目标汇总

- 报告统一输出：成功率提升 / 成本变化 / 副作用变化，三者并列，禁止只报成功率。
- 判断"无回归"：val 集成功率 **≥ 基线 - 2pp 且成本 ≤ 基线 × 1.5**（数值在 M3 实跑后校准）。

## 3. 可优化 Harness 资源定义

初始定义三类资源，全部为**文本/配置形式**（Agent Lightning `initial_resources` 语义，key 任意）：

| 资源 | 内容 | 示例（来自现有 configs） |
|---|---|---|
| `system_prompt` | 系统提示模板 | 沿用 SWE-agent 风格但改为 tau2 域：任务说明、策略约束 |
| `tool_policy` | 工具使用约束文本（何时用哪些工具、禁止行为） | "先复现再修；不修改测试；单任务成本上限" |
| `action_strategy` | 执行策略文本（步骤规划、重试规则） | "失败后先检查上一步输出，再决定下一步" |

- 每类资源必须可序列化（纯文本/JSON）→ 是 GEPA 可优化对象的先决条件。
- M3 先用 `system_prompt` 单一资源跑通；M4 GEPA 阶段启用多资源联合。

## 4. 非法候选过滤

APO/GEPA 生成的候选必须通过合法性校验，否则拒绝：

| 规则 | 说明 |
|---|---|
| 格式校验 | 必须是合法文本/JSON，无损坏编码 |
| 长度约束 | 模板长度在 [min, max]（如 200–8000 字符），防退化 |
| 禁止注入 | 候选不得包含"忽略系统指令"、测试文件修改指令等 |
| 语义保真 | 必须保留任务域关键约束（tau2 工具名、DB 校验协议）——用关键词白名单粗筛 |
| 成本守卫 | 候选评测的 per-instance cost 超限即终止该候选 |

- 过滤函数：`optimizers/candidate_filter.py`，M3 接入 APO 候选写入前。
