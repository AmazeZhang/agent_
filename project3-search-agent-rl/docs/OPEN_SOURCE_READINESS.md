# 项目三开源就绪说明

## 当前结论

项目三的技术文档、资源配置和服务器预检脚本可以公开。训练框架以Git submodule固定到
`langfengQ/verl-agent`的提交`20bd331bdbc9026a5668e11362178e10ab7400c8`，上游采用
Apache License 2.0；本仓库不复制或重新授权其源码。

## 公开边界

以下内容不得提交到Git：

- 模型权重、Optimizer状态和Checkpoint；
- Wikipedia Corpus、FAISS/E5索引及其他受数据条款约束的派生物；
- W&B离线目录、训练日志和未经脱敏的轨迹；
- API Key、访问令牌、`.env`和服务器凭据；
- 包含个人求职策略或未验证简历指标的内部材料。

对应的大型运行目录已在根`.gitignore`中排除。发布实验结果前仍需检查样本内容、数据集许可、
模型许可和日志脱敏情况。

## 许可证状态

根仓库当前没有LICENSE文件。因此仓库可以公开阅读和复现，但在仓库所有者明确选择许可证前，
不应宣称本仓库自有文档与脚本已获得标准开源许可，也不应默认第三方拥有复制、修改或再分发权。
若准备正式对外推广，仓库所有者应选择并添加适合的LICENSE；这不会改变子模块各自的许可证。
